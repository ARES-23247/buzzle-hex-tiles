# Archive — historical references, not the current print set

Use the [current print library](../output/README.md) to choose files to print.

This folder keeps earlier designs and references out of the active outputs:

- [61-cell BUZZELLO board](printed-revisions/2026-09-06-before-91-cell-buzzello/README.md):
  the v3 print set saved before adding a 30-cell outer ring.
- [Previous printed board versions](printed-revisions/2026-09-05-before-thicker-boards/README.md):
  the complete print sets saved before the thicker September 5 revision.
- `legacy-outputs/`: previous boards, prototypes, old previews, reference
  photographs, and design experiments. Some older meshes have known issues.
- `legacy-documents/`: older rules, the 1.5-inch paper board/print hub, and the
  previous project guides. Dimensions, quantities, and local links inside these
  documents may be outdated.

Exact duplicate copies were removed only after comparing SHA-256 hashes.
Distinct older models and artwork were preserved. The separately authorized
1.5-inch tile STL/3MF deletion was completed earlier; those files are not
reintroduced by this archive.

See [the migration record](../docs/maintenance/output_migration.json) for the
initial source/destination map. Current generators and refreshed previews may
subsequently rewrite active files; the record describes the migration snapshot.
