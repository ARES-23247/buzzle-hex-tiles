# Board sets saved before the thicker revision

Saved September 5, 2026, before applying feedback from the printed Othello board.
These are complete copies of the earlier model sets, guides, manifests, and previews.
The two generator files are reference snapshots; use the active root generators
to generate current boards. Links inside the copied guides retain their original context.

| Earlier set | Divider | Floor | Pocket depth | Total height |
|---|---:|---:|---:|---:|
| [BUZZLE plates](buzzle/plates/) | 1.4 mm | 2.0 mm | 2.0 mm | 4.0 mm |
| [Othello plates](othello/plates/) | 1.4 mm | 2.4 mm | 0.8 mm | 3.2 mm |

Use these only to match earlier prints. The current sturdy versions have wider
cell spacing and must be printed as complete sets; their sections will not align
with these versions. Both generations fit the same 33.02 mm / 1.3-inch tiles.
