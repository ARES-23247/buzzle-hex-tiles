# Seven-tile holders

These retained accessories are organized here without changing their geometry.

- [Single holder](3mf/tile_holder_single_7tiles.3mf)
- [Four-holder plate](3mf/plate_256_tile_holders_4pack.3mf)
- [Single holder STL](stl/tile_holder_single_7tiles.stl)

Print at 100% scale. Start with one holder and check it with an existing
33.02 mm tile before printing the four-pack. Use the 270 mm printer profile
and inspect bed placement in the slicer; these accessory files have not been
re-sliced or physically validated during the board cleanup.

The `images/` folder retains the existing holder illustration.
