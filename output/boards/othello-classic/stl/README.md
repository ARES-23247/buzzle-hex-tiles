# STL printing

Print at 100% scale in millimeters. Use either the single-color file or the
matching Black and Yellow color-part files, never both sets together.
STL stores geometry only. For two-color printing, import both color parts
as one multipart object, keep their original shared coordinates, and assign
black/yellow filaments manually. Do not center or drop each part separately.
The 3MF files in ../plates already preserve this alignment and color metadata.
Flush color markings disappear in the single-color version.
