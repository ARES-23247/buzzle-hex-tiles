# FIRST season branding used in Printables listings

User-approved scope: listing images and descriptions only. Printed tile artwork is unchanged.

Official sources reviewed September 5, 2026:
- https://www.firstinspires.org/resources/library/season-brand-downloads
- https://www.firstinspires.org/hubfs/web/brand/season/2027/downloads/ftc-biobuzz-styleguide.pdf?hsLang=en

- https://www.firstinspires.org/hubfs/web/about/policy/ip-policy-trademarks-copyrighted-materials-first-lego.pdf?hsLang=en

The downloaded digital FTC/BIOBUZZ/RTX lockup is used unchanged in the gallery.
Keep its colors, proportions, sponsor mark and built-in clear space. The season
guide specifies a minimum digital width of 336 pixels and printed width of
3.5 inches. Use BIOBUZZ in capitals, with a trademark symbol on the first
headline and body mention, and "presented by RTX" on the first body mention.
Identify ARES FTC 23247 separately; do not combine the team name with the logo.

Official FIRST and RTX artwork remains the property of its respective owners;
the model's Creative Commons license does not relicense this branding.
The original logo archive is reference material, not part of the model download bundles.

Verified game links:
- https://aresfirst.org/buzzle
- https://aresfirst.org/buzzello
- https://aresfirst.org/buzzle/word-tools

The word-tools page includes a word checker, dictionary and two-letter list.
It states no sign-in is required; the checker/list support offline use after
setup, while new definitions require internet.

Printables' interactive preview was inspected on an uploaded individual A tile:
it displays generic orange and hides the flush lettering visually. The uploaded
geometry renders show the intended colors. Do not describe the interactive
viewer as color-accurate; the 3MFs separately include verified material colors,
per-face colors and explicit filament-slot metadata.

Viewer compatibility checks: object defaults referencing the color group,
portable six-digit colors without slicer metadata, and a single merged colored
mesh all still rendered orange. No universal Printables limitation is inferred;
these particular compatibility tests did not resolve its live rendering.
Experimental downloads were removed and the standard A tile restored.

See VIEWER_RESEARCH.md for the documented color-group solution and the current
reference-model comparison. The reference also rendered orange.
